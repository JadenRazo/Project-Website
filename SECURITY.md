# Security policy

## Supported code

Only the latest `main` branch is considered for security fixes. This public repository does not provide a supported deployment or availability commitment.

## Reporting

Use GitHub private vulnerability reporting when it is available. Otherwise email `contact@jadenrazo.dev` with the affected path, impact, and a minimal reproduction.

Do not open a public issue containing:

- credentials, tokens, session material, or private keys
- contact messages, visitor records, authentication data, or database contents
- internal hostnames, network inventory, or deployment credentials
- a working exploit against a reachable service

## Scope

The repository includes a browser application, Go services, example deployment configuration, and historical packages. A configuration file being present does not mean that the public production environment uses it unchanged. Dependency vulnerabilities should also be reported to the relevant upstream project.
